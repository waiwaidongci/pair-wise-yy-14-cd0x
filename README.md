# hxyfront-62013 木构榫卯试装放线台

源提示词编号：8（由"木结构榫卯构件测绘"升级为试装放线台）

古建筑木结构榫卯构件的试装放线管理前端。规则判断、状态存储与操作界面三层分离：

```
src/
  domain/   规则判断层（纯函数，无界面、无存储依赖）
    types.ts    领域类型与业务常量（榫型允许间隙、含水率上限 18%）
    rules.ts    双检走向、占位检查、间隙判定、组指纹、失效留档、结论口径
  store/    状态存储层
    storage.ts  localStorage 持久化与演示数据种子
    useBench.ts React 桥接：所有变更经规则层判定后落库，自动持久化
  ui/       操作界面层（只调用 store 动作，不直接改状态）
    BatchPanel / SlotBoard / ComponentPanel / GroupPanel / RelationView / TrialLog
```

## 业务规则

1. 试装批按 **建筑 + 轴线** 锁定，同建筑同轴线只允许一个批，编组与换件不得跨批。
2. 构件须先完成 **病害复核** 与 **含水率检测**；含水率 > 18% 或关键截面缺损 → 只能送修，不得占试装位。
3. 一个试装位同时只接纳一组构件，按榫型允许间隙判定（燕尾榫 1.5 / 透榫 2.0 / 半榫 2.5 / 箍头榫 1.0 mm）。
4. 超限退回修配；修配后必须重新测量（复测登记）才能复装。
5. 试装通过后更换任一构件 → 整组结论立即失效，旧记录留档，按新件重判。
6. 重复试装（批 + 构件集合 + 测量版本一致）沿用首次结果，不产生新记录。
7. 队列、构件关系视图与结论均来自同一份持久化状态，刷新后一致恢复。
