# hxyfront-62013 木构榫卯试装放线台

源提示词编号：8

由「木结构榫卯构件测绘」升级为试装放线台，按三层分离实现：

- **规则判断**（`src/domain/rules.ts`，纯函数）
  - 构件须先完成病害复核与含水率检测；含水率 > 18% 或关键截面缺损 → 只能送修，不得占试装位
  - 试装批按「建筑 + 轴线」锁定，编组/换件不得越轴
  - 一个试装位同时只接纳一组构件
  - 按榫型允许间隙判定（燕尾榫 ≤1.5mm、透榫 ≤2.0mm、半榫 ≤1.0mm、箍头榫 ≤0.8mm），超限退回修配
  - 修配后必须重新测量才能复装
  - 试装通过后更换任一构件 → 整组结论立即失效，旧记录留档并按新件重判
  - 重复试装沿用首次结果（按构件集合签名幂等）
- **状态存储**（`src/store/trialStore.ts`）：全部状态集中于独立 store，动作内调用规则层；每次变更写入 localStorage，刷新后队列、构件关系视图与判定结论保持一致
- **操作界面**（`src/ui/`）：试装批侧栏、构件登记/检测/清单、试装台（编组、上位、测量判定、修配复装、更换构件）、构件关系视图、试装记录与留档

## 技术栈

React + Vite + TypeScript
